API & Architecture Reference

系统架构与开放接口规范

TranslatePet.Core.Interfaces.ITranslationService

核心翻译服务接口 (ITranslationService)

提供跨语言翻译调度。支持通过 TranslationStyle 切换口语/标准/商务模式，并支持动态注入自定义 Prompt。 

public interface ITranslationService
{
    /// <summary>
    /// 执行文本翻译
    /// </summary>
    /// <param name="text">待翻译源文本</param>
    /// <param name="sourceLang">源语言（如 "auto", "en", "zh-CN"）</param>
    /// <param name="targetLang">目标语言（如 "zh-CN", "en"）</param>
    /// <param name="style">翻译风格：Conversational, Standard, Formal</param>
    /// <param name="customPrompt">可选动态注入的专属提示词（留空使用系统配置）</param>
    /// <param name="cancellationToken">取消令牌</param>
    Task<TranslationResult> TranslateAsync(
        string text,
        string sourceLang,
        string targetLang,
        TranslationStyle style = TranslationStyle.Conversational,
        string? customPrompt = null,
        CancellationToken cancellationToken = default);
}
参数名 类型 说明
text string 需要翻译的原始文本，支持多行与各类长短句。
style TranslationStyle 枚举值：Conversational(口语地道, 默认), Standard(通用标准), Formal(商务正式)。
customPrompt string? 可覆盖默认系统 Prompt 的定制提示词，实现高度个性化控制。
TranslationResult class 包含 TranslatedText(译文), DetectedLanguage, ProviderName, LatencyMs 等字段。
TranslatePet.Core.Interfaces.IVocabularyService

艾宾浩斯生词本与复习服务 (IVocabularyService)

负责生词持久化（vocabulary.json）、艾宾浩斯抗遗忘记忆曲线调度算法、复习反馈与每日统计。 

public interface IVocabularyService
{
    /// <summary>获取当前已到期需要复习的单词列表</summary>
    Task<IReadOnlyList<VocabularyItem>> GetDueWordsAsync(int limit = 20);

    /// <summary>记录一次复习反馈并依据艾宾浩斯曲线计算下一次复习时间</summary>
    Task RecordReviewAsync(string id, ReviewFeedback feedback);

    /// <summary>收藏新单词到生词库</summary>
    Task<VocabularyItem> AddWordAsync(
        string word,
        string definition,
        string phonetic = "",
        string contextSentence = "",
        string contextTranslation = "",
        string memoryHack = "");

    /// <summary>获取生词本全局统计数据</summary>
    Task<VocabularyStats> GetStatsAsync();
}
反馈类型 (ReviewFeedback) 算法行为 复习周期推进
Remembered (完全记住) ReviewStage + 1, 连续正确次数 + 1 依次按 1天 -> 2天 -> 4天 -> 7天 -> 15天 -> 30天 排程
Fuzzy (有些模糊) 保持当前 Stage，不向上晋级 固定在 1~2 天内再次触发复习
Forgotten (完全遗忘) ReviewStage 重置回退为 0 安排在 12 小时内紧急重温强化

Quick Start & Configuration

新手使用说明与配置指南

仅需三步，开启丝滑的桌宠翻译与背单词体验

1

启动桌宠与呼出菜单

双击运行 TranslatePet.UI.exe，可爱的哆啦A梦桌宠将直接出现在桌面右下角。右键点击桌宠可呼出主菜单：
• 📚 单词本与每日复习
• ⚙️ 系统设置面板
• 退出桌宠

2

配置大模型翻译密钥

进入【设置 -> 翻译源设置】：
• API 端点：填入兼容 OpenAI 规范的 BaseUrl（如 DeepSeek https://api.deepseek.com/v1 或硅基流动、Kimi）
• 模型名称：deepseek-chat / gpt-4o-mini
• API 密钥：填入对应平台的 API Key

3

设置全局快捷键与划词

进入【设置 -> 快捷键与提醒】：
• 划词翻译：默认推荐 F4（单键极速触发）
• 截图翻译：默认推荐 Alt + Q
• 在任何软件中选中外语文本，按下 F4，即刻呼出精美翻译弹窗！

4

定制专属提示词与每日提醒

进入【设置 -> 专属提示词定制】：
• 5 种模式对应的 Prompt 随意修改，支持【恢复默认配置】。
• 勾选【开启每日背单词提醒】，设定每日提醒时间（如 20:00）和复习目标（如 20 词）。
